### Requisitos

Tener instalado el SDK de .NET compatible con el archivo `.csproj`.

### Desde la terminal

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Entrar en la carpeta del proyecto que desea ejecutar (por ejemplo el de impresion):

   ```bash
   cd SistemaImpresion
   ```

3. Ejecutar la aplicación:

   ```bash
   dotnet run
   ```


##  Diagrama de diseño

El archivo `diseñoApp.drawio` contiene el diagrama de diseño del sistema y puede abrirse o editarse desde la web utilizando [draw.io](https://app.diagrams.net/).

Para visualizarlo, descargá el archivo y abrilo desde la opción **Archivo → Abrir desde → Dispositivo**.
